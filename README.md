# LMSGI · Ejercicios y ejemplos de clase · 2026–2027

Repositorio de **Lenguajes de Marcas y Sistemas de Gestión de Información** con los ejercicios y ejemplos que realizamos en clase durante el curso 2026–2027.

Se irá ampliando a lo largo del curso con prácticas relacionadas con los distintos **resultados de aprendizaje (RA)** del módulo.

## Cómo utilizarlo

- Consulta los ejemplos para repasar las explicaciones y continuar las prácticas.
- Descarga el repositorio desde **Code → Download ZIP** o clónalo con Git.
- Sigue las indicaciones de clase para trabajar con cada ejercicio.

Los ejemplos se construyen y revisan en el aula, por lo que pueden incluir pasos intermedios y aspectos pendientes de mejorar.
